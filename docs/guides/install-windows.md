# Install on Windows (Edge or Chrome)

The app is a Progressive Web App — it installs like a normal program, works
offline, and updates automatically.

## Steps

1. Open **Microsoft Edge** or **Google Chrome**.
2. Go to your app address (e.g. `https://your-cafe.vercel.app`).
3. Sign in once so the app is cached.
4. Click the **Install** icon in the address bar (a small screen/monitor icon),
   or open the browser menu → **Apps → Install this site as an app**.
5. Confirm. A desktop/Start-menu shortcut named **Sixty's** is created.

## Notes

- The app opens in its own window, full-screen capable, keyboard-friendly.
- It keeps working if the internet drops; sales are queued and sync when back
  online (watch the online/offline indicator in the top bar).
- To update: just reopen it — updates apply automatically.
- To uninstall: open the app → menu (…) → **Uninstall**, or remove it from
  Windows _Installed apps_.
